List animation

Two independent lists, same API. Add and Shuffle act on both; the ✕ button removes from its own list only. Every change is wrapped in MorphService.run.

Named

Each row has an explicit id: [morph]="'item-' + id" with morphClass="morph-list-item". Works in every browser with View Transitions.

    @for (item of named(); track item.id) {
  • {{ item.label }}
    • }

Auto

No ids: morph="auto" lets the browser name each row (view-transition-name: match-element, Chrome 137+).

    @for (item of auto(); track item.id) {
  • {{ item.label }}
    • }
